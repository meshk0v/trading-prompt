# tplevels

Библиотека расчёта **ценовых уровней и зон** на чистом JavaScript. Без зависимостей, работает в браузере и на Node.js (ESM).
Все функции чистые: на входе массив свечей, на выходе обычные объекты, которые можно сразу отдать в JSON или вставить в промпт.

```bash
npm test                 # 14 тестов
node examples/demo.mjs   # пример на случайных данных
```

## Формат свечей
```js
{ time: 1767225600000, open, high, low, close, volume }   // time в мс (секунды определяются автоматически)
```
Свечи упорядочены по времени, от старых к новым. `volume` нужен только для профиля объёма.

## Быстрый старт
```js
import { analyzeLevels, nearestLevels, levelsToText } from './src/index.js';

const r = analyzeLevels(candles);          // все виды уровней за один вызов
console.log(levelsToText(r, { above: 6, below: 6, lang: 'ru' }));   // текст для промпта
const near = nearestLevels(r, { above: 3, below: 3 });              // ближайшие уровни как объекты
```
Отключить или настроить секцию: `analyzeLevels(candles, { fvg: false, sr: { tolAtr: 0.8 }, tzOffsetHours: 3 })`.

## Что считает

| Функция | Что возвращает |
|---|---|
| `findSwings`, `zigzag` | Свинги (фракталы) и ZigZag по % или ATR. У последнего пивота `confirmed: false`. |
| `roundLevels` | Круглые уровни вокруг цены, отметка `major`. Шаг определяется автоматически или задаётся `step`. |
| `fibRetracement`, `fibExtension`, `fibProjection`, `autoFib` | Коррекции, расширения ABC, проекции. `autoFib` берёт последнюю завершённую ногу ZigZag и считает, на какой доле коррекции сейчас цена. |
| `pivotPoints`, `pivotsFromCandles` | Classic, Fibonacci, Woodie, Camarilla, DeMark. Day/week/month по прошлому периоду. |
| `periodLevels`, `sessionRanges` | PDH/PDL/PDC, PWH/PWL, PMH/PML, открытия DO/WO/MO; high/low сессий (Asia, London, NewYork). |
| `findTrendlines`, `trendChannel` | Линии поддержки (по лоям) и сопротивления (по хаям): наклон, касания, текущее значение. Канал параллельной линией. |
| `regressionChannel` | Канал линейной регрессии ± N стандартных отклонений, `r2`. |
| `srZones` | Горизонтальные зоны S/R: кластеры свингов, `touches`, `flipped` (смена роли), положение относительно цены. |
| `supplyDemandZones` | Зоны спроса и предложения (база + импульс), статус fresh / tested / broken. |
| `fairValueGaps` | Имбаланс из трёх свечей (FVG), заполнение в %. |
| `orderBlocks` | Упрощённые ордер-блоки по пробою структуры (BOS). |
| `consolidationRanges` | Боковые диапазоны и направление выхода из них. |
| `volumeProfile` | POC, VAH, VAL, HVN/LVN по свечному объёму. |
| `analyzeLevels`, `flattenLevels`, `nearestLevels`, `levelsToText` | Всё сразу, плоский список с расстояниями до цены, ближайшие уровни, текст для промпта. |

Единицы измерения: цена в пунктах инструмента; допуски и пороги задаются в ATR (`tolAtr`, `impulseAtr`, ...), поэтому настройки переносятся между инструментами.

## Индикаторы (`analyzeIndicators`, входят в `analyzeLevels().indicators`)
По одному представителю от каждого класса, а не все варианты. Параметры меняются через `{ params: { ema: 50, rsi: 14, ... } }`.

| Класс | Индикатор |
|---|---|
| Скользящая средняя | EMA(20): положение цены, расстояние в ATR, наклон |
| Сила тренда | ADX(14) с +DI/-DI |
| Трейлинг-тренд | Supertrend(10, 3): направление, уровень, бар смены |
| Облачная система | Ichimoku (нужно ≥78 баров) |
| Структура рынка | HH/HL/LH/LL по свингам |
| Моментум | RSI(14) + дивергенции с ценой |
| Тренд-моментум | MACD(12, 26, 9): гистограмма, пересечение |
| Положение в диапазоне | Stochastic(14, 3, 3) |
| Волатильность | ATR(14): состояние растёт/падает |
| Канал волатильности | Bollinger(20, 2): %B, сжатие |
| Пробойный канал | Donchian(20): позиция, пробой |
| Цена × объём | VWAP (дневной, учитывает `tzOffsetHours`) |
| Поток объёма | OBV: подтверждает ли цену |
| Активность | Относительный объём (RVOL 20) |
| Свечные паттерны | doji, pin bar, engulfing, inside/outside bar, marubozu |

Объёмные индикаторы включаются, только если в свечах есть `volume` (тиковый объём тоже годится, укажите `volumeKind: 'tick'`). Серии и тексты: `history: N` отдаёт массивы последних N баров, `indicatorsToCSV` превращает их в таблицу, `indicatorsToText` даёт текст для промпта (`lang: 'ru' | 'en'`). Поле `votes` это простой подсчёт бычьих и медвежьих сигналов, а не торговая рекомендация.

## Готовый промпт (`buildPrompt`)
```js
const r = analyzeLevels(candles, { indicators: { history: 30, volumeKind: 'tick' } });
const text = buildPrompt(r, candles, { symbol: 'EURUSD', timeframe: '1h', bars: 30, lastBarOpen: true, volumeKind: 'tick', lang: 'ru' });
```
Собирает: шапку (актив, таймфрейм, текущая цена, время последней свечи в UTC), уровни, индикаторы и одну таблицу последних `bars` свечей (OHLCV и колонки индикаторов). Блоки отключаются: `levels: false`, `indicators: false`, `bars: 0`. Отдельно доступна `candlesTable`.

## Что важно знать
- **Трендовые линии, зоны, ордер-блоки и FVG не имеют единого стандарта.** Здесь реализованы чёткие правила, описанные в комментариях к функциям. Другие трейдеры и платформы построят другие линии. Параметры настраиваются, для сравнения с TradingView сверяйте результат вручную.
- **Свинги подтверждаются с задержкой** в `right` баров (по умолчанию 3), поэтому последние бары не дают свингов. Это сделано намеренно, чтобы уровни не перерисовывались.
- **Профиль объёма из свечей приблизительный**: объём свечи равномерно распределяется по её диапазону. Для точного профиля подавайте тиковые данные, агрегированные по уровням цены.
- **Трендовые линии заданы в индексах баров**, а не во времени. Для отрисовки на графике переведите индекс в время через свечи.
- **Order flow (дельта, CVD, footprint) по свечам не считается**: для него нужны сделки с признаком агрессора.
- Это инструмент расчёта, а не торговая рекомендация.
