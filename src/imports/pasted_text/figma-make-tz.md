Как я бы сформулировал задачу для Figma Make

Можно дать ей такой принцип:

Создай демонстрационные данные для 100 индикаторов технического анализа. Все значения должны быть синтетическими и использоваться только для UI-прототипа. Не называй их реальными рыночными данными. Генерируй значения в заданных диапазонах. Значения должны быть взаимосвязаны между собой в зависимости от текущего сценария: Bullish, Bearish или Neutral. Не генерируй каждый индикатор независимо. При смене сценария плавно изменяй значения индикаторов, сохраняя логическую корреляцию между ними.

И ещё лучше сделать в интерфейсе переключатель Bullish / Neutral / Bearish, чтобы Figma Make автоматически перестраивала все 100 показаний согласованно.

Если это для твоего ИИ-сервиса сигналов, я бы пошёл ещё дальше: сделать не просто 100 показаний, а 100 индикаторов → нормализация → итоговый Score от -100 до +100 → BUY / SELL / NEUTRAL, чтобы эти данные визуально выглядели как настоящий аналитический движок.
