Да. Ниже готовая **единая чёрно-белая дизайн-система**, чтобы в Figma Make можно было использовать одни и те же цвета для всех элементов. Контраст намеренно мягкий.

### 1. Основные поверхности

| Элемент               | Цвет      | Описание                                           |
| --------------------- | --------- | -------------------------------------------------- |
| **Фон**               | `#0A0A0A` | Основной фон приложения                            |
| **Блок на чёрном**    | `#111111` | Карточки, панели, секции                           |
| **Рамка блока**       | `#1C1C1C` | Обычная граница карточек                           |
| **Поля внутри блока** | `#161616` | Input, Select, Textarea                            |
| **Внутри полей**      | `#1D1D1D` | Вложенные области, значения, элементы внутри input |

### 2. Текст

| Элемент                 | Цвет      | Описание                     |
| ----------------------- | --------- | ---------------------------- |
| **Основной текст**      | `#E6E6E6` | Заголовки, основной контент  |
| **Вторичный текст**     | `#8A8A8A` | Подписи, описания            |
| **Неактивный текст**    | `#555555` | Disabled-состояния           |
| **Placeholder**         | `#5F5F5F` | Текст-подсказка внутри полей |
| **Текст на hover**      | `#F0F0F0` | Когда элемент наведен        |
| **Максимальный акцент** | `#FFFFFF` | Только самые важные элементы |

# 21. Состояния элементов — общая логика

Чтобы весь интерфейс выглядел единообразно:

**Default**

> Спокойный, минимальный контраст.

**Hover**

> Немного светлее фон + немного светлее рамка.

**Pressed**

> Фон немного темнее или насыщеннее, чем Hover.

**Focus**

> Более заметная, но всё ещё сдержанная рамка `#383838–#444444`.

**Active**

> Текст становится `#E6E6E6–#FFFFFF`, фон `#1C1C1C–#242424`.

**Disabled**

> Уменьшаем контраст, а не просто ставим opacity на весь компонент.

## Итоговая базовая палитра

```text
#0A0A0A — основной фон
#111111 — блок
#161616 — поле
#1C1C1C — рамка / разделитель
#1D1D1D — внутренний элемент
#222222 — scrollbar / вторичный элемент
#242424 — hover / active
#292929 — hover border
#333333 — усиленная рамка
#383838 — focus
#444444 — активный/сильный элемент
#555555 — disabled text
#777777 — secondary icon/text
#8A8A8A — secondary text
#A8A8A8 — muted bright
#BDBDBD — icon / slider
#D8D8D8 — основной светлый элемент
#E6E6E6 — основной текст
#FFFFFF — максимальный акцент
```

**Главное правило для твоего интерфейса:** `#FFFFFF` не должен быть обычным цветом интерфейса. Пусть он появляется только в **активных состояниях, ключевых кнопках, важных цифрах и наиболее приоритетных элементах**. Это даст тот самый спокойный, дорогой и малоконтрастный вид.
